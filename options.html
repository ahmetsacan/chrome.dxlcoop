Google Routes API

DxlCoop can use the Google Routes API to calculate estimated driving distances to job locations.


Obtaining a Google Routes API Key

  1. Visit the Google Cloud dashboard .
  2. Create a Project if you don't already have one.
  3. Click the Enable APIs and services button.
  4. Search for Routes API and select Routes API from the search results.
  5. Select Enable.
  6. Follow the instructions to enable the API. Google may ask for a credit card as part of signing up for Google Cloud. Select the free option where available. Usage within Google's applicable free usage limits will not incur charges.
  7. You will be shown the API key to copy. Copy it. Then proceed to manage the Maps API.
  8. If given the option to Protec your API key, you may select restriction type "API restriction" and then select Routes API
  9. You should get to the Overview page to enable API(s).
